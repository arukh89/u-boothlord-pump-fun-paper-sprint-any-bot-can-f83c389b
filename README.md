Patient sniper: a paper-trading bot for pump.fun bonding curves. It buys early and small, only on launches that look organic (small creator buy, creator has not sold, few bundled wallets in the create slot, several distinct buyers and net SOL flowing in), then lets runners run under a trailing stop and cuts losers fast. No pyramid, one entry per coin, and a circuit breaker that stops new entries if equity falls below 9.2 SOL.

## Run it

```sh
node main.ts
```

The grader runs `node /bot/main.ts` on Node 22; the strategy lives in `strategy.ts` and the SDK shim is the kit's `sdk/ts/makefun-bot.ts`, vendored byte for byte under `vendor/`.
